# OVA - Mantenimiento de Motores Diesel

## 📖 Descripción
Objeto Virtual de Aprendizaje (OVA) desarrollado para el SENA, enfocado en la enseñanza del mantenimiento de motores diesel. Este proyecto incluye contenido interactivo, juegos educativos y material multimedia.

## 🚀 Características
- **Página de Bienvenida**: Introducción con video educativo integrado
- **Contenido Principal**: Información estructurada sobre motores diesel
- **Sección Explora**: Galería de imágenes y recursos descargables
- **Juego Educativo**: Memoria interactiva para reforzar el aprendizaje
- **Diseño Responsive**: Adaptado para dispositivos móviles y desktop

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica
- **CSS3**: Diseño moderno con gradientes, animaciones y efectos visuales
- **JavaScript**: Interactividad y funcionalidad de modales
- **Responsive Design**: Compatible con diferentes tamaños de pantalla

## 📁 Estructura del Proyecto
```
├── Bienvenida.html          # Página de inicio con video
├── index.html               # Contenido principal 
├── explora.html             # Galería y recursos
├── Juego dememoriapregunta.html  # Juego interactivo
├── img/                     # Recursos gráficos
│   ├── image-1.png         # Logo SENA
│   ├── fondointegradochica.png  # Imagen de fondo
│   └── img1/               # Imágenes del juego
├── El Mantenimiento de Motores Diesel.mp4  # Video principal
└── CARTILLA.pdf            # Material de apoyo
```

## 🎮 Funcionalidades
- Modal de video con controles avanzados
- Juego de memoria con sistema de vidas
- Navegación fluida entre secciones
- Enlaces a redes sociales del SENA
- Descarga de recursos educativos

## 📱 Responsive Design
- **Desktop**: Experiencia completa con todas las funcionalidades
- **Tablet**: Adaptación de layouts y controles
- **Mobile**: Interfaz optimizada para pantallas pequeñas

## 🔧 Instalación Local
1. Clona este repositorio
2. Abre `Bienvenida.html` en tu navegador
3. Asegúrate de tener el video `El Mantenimiento de Motores Diesel.mp4` en la raíz

## 🌐 GitHub Pages
Este proyecto está optimizado para funcionar con GitHub Pages. Simplemente activa Pages en la configuración del repositorio.
